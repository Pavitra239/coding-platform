# 🧠 Coding Platform – Automated Code Assessment System

A full-stack automated coding assessment platform built using the **MERN stack**.  
The platform allows users to submit code and receive evaluated results, reducing the need for manual code review and enabling faster feedback cycles.

This project was built to solve real-world problems around scalable and consistent code evaluation.

---

## 🚀 Key Capabilities

- Secure code submission and evaluation
- Backend APIs for handling submissions and results
- Frontend interface for interacting with the platform
- Designed to integrate with sandboxed execution engines (e.g., Judge0)
- Supports end-to-end workflow from submission to evaluation

---

## 🛠️ Tech Stack

- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** PostgreSQL / MongoDB
- **Execution:** Judge0 (sandboxed code execution)
- **Dev Tools:** Docker, Git

---

## 🏁 Project Setup

### Client setup
```bash
npm run setup-client
```

### Server setup
```bash
npm run setup-server
```

### Setup entire project
```bash
npm run setup-project
```

## ▶️ Running the Application

### Run only server
```bash
npm run server
```

### Run only client
```bash
npm run client
```

### Run full application (client + server)
```bash
npm run dev
```
